not a claim of legal clearance for third-party materials. The repository is
public. Its MIT license applies to original project work; it grants no rights

The Twinleaf inventory is generated by the unchanged `twinleaf-audit.mjs`:
walk TypeScript set files, skip `.spec.ts`, extract exported classes and literal
metadata, hash each source file, mark every row `script-present-unverified`,
then serialize JSON. Its original generation timestamp is not recorded in the
source artifact. This export records its collection date, exact input revision
and file digest instead of inventing a timestamp. It was regenerated locally
on 2026-10-23 for comparison. See `coverage/reuse-verification.json` for results.

For original code, the Git commit is the creation/revision identity. Historical
experiment dates and recorded source pins remain intact. Original acquisition
times for older external inputs are not always recorded; filesystem modification
times have not been treated as collection evidence. We copied committed blobs,
not dirty source files, caches, source histories or live training outputs.

## Upstream credit and governing notices

**Twinleaf / ryuu-play.** Twinleaf's pinned [README](https://github.com/twinleafgg/twinleafgg/blob/d89efe580127a05aff8b0456fd2ad587edbbee2d/README.md)
credits Keeshii and TheEPSD and the [ryuu-play foundation](https://github.com/keeshii/ryuu-play).
It and the pinned [server package](https://github.com/twinleafgg/twinleafgg/blob/d89efe580127a05aff8b0456fd2ad587edbbee2d/ptcg-server/package.json)
declare MIT. No standalone LICENSE was found at this revision. We therefore
provide the existing pinned retrieval procedure instead of bundling its engine
or supplying an invented copyright notice. Retain upstream notices and resolve
the full notice before a future vendored distribution. Pokemon card text and
artwork have separate rights; the project MIT license supplies none. Twinleaf
prohibits LLM-generated upstream contributions; this change submits none there.

**Tooling.** Twinleaf preparation installs TypeScript 4.3.5 and
`@progress/pako-esm` 1.0.1 using the retained integrity-locked package files and
`--ignore-scripts`. TypeScript's Apache-2.0 notice and pako's MIT-style Progress,
Vitaly Puzrin and Andrei Tuputcyn notices stay in their downloaded packages.
Those packages and their source are not redistributed by this repository.

**CABT / Kaggle.** The inspected Kaggle framework checkout is
[`Kaggle/kaggle-environments` f994f2050d58d84f649329c1e35ce09ada7007c5](https://github.com/Kaggle/kaggle-environments/tree/f994f2050d58d84f649329c1e35ce09ada7007c5).
Its root [Apache-2.0 license](https://github.com/Kaggle/kaggle-environments/blob/f994f2050d58d84f649329c1e35ce09ada7007c5/LICENSE)
does not override the separate competition-engine restrictions. The acquired
`ptcgProgram` package's README and
`LICENSES/LicenseRef-PTCG-ABC-Competition-Use-Only.txt` explicitly prohibit public
redistribution and cover adaptations. The modified engine inspected here has
local commit `7e9e42007b87f05922e068a14f2ace322127aa96`; it has no public remote.
Its upstream package has no verified immutable public download URL in this
review. Do not mistake that local commit for a public source release.
The governing primary-source entry is the [competition rules](https://www.kaggle.com/competitions/pokemon-tcg-ai-battle/rules).
The web page did not expose readable rules text during this review; the
package notices are sufficient to reject publication, not to authorize use.
We did not accept new terms, obtain new permissions or run this engine.

The inspected competition license has SHA-256
`0bc3060e440432fa9481071ee9531d0d34e7212b1b6ffe595e38b9c9cd9c081b`;

`b8a6be5fb9fecc24780cf73c904c55828ce1b07462ae044fd1d3f2a03f0bb100`.
